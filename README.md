# Aurora

Design system do Bmg: tokens, componentes (React + shadcn/Radix) e documentação no Storybook.

```bash
pnpm install
pnpm storybook        # abre o Storybook
pnpm build            # confere tokens e tipos
pnpm build-storybook  # gera o Storybook publicável
```

Trabalhando com o Claude Code: as regras do projeto estão no [CLAUDE.md](CLAUDE.md) e o harness (skills, travas e scripts) em [.claude/README.md](.claude/README.md).
